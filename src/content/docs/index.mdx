<HomeSection id="model-in-browser" titlu="Un model de limbaj, direct în browser">
  Modelul din această conversație rulează pe propriul calculator, nu pe un server. **SmolLM2 135M** are de peste 1.000 de ori mai puțini parametri decât GPT-3, iar biblioteca [Transformers.js](https://huggingface.co/docs/transformers.js) îl rulează pe placa grafică (WebGPU) sau pe procesor (WebAssembly). Răspunsul apare token cu token, pe măsură ce este generat.

  În laboratorul despre modelele de limbaj locale facem același lucru în Python, pe propriul calculator: descărcăm de pe Hugging Face Hub un model cu ponderi deschise, apoi refacem pas cu pas tokenizarea, șablonul de chat și generarea.
